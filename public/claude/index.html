Under the hood — rationale, reusable API & requirement map ↗

Design rationale. Claude treats motion as a material: warm paper, expressive serif, quiet clay accents and a green sculptural world keep the collection human. A common spring solver makes magnetic attraction, spatial depth and gesture settling feel related. Each interaction earns its movement through purpose, while reduced motion retains the same composition and clarity.

Reuse. Copy this entire file, or copy its shared CSS, shared runtime and the desired custom element. Light DOM keeps content semantic and available before JavaScript. Override tokens on any host. All components accept state="ready|loading|empty|error", expose destroy(), and dispatch bubbling claude:state events. Removing a host aborts listeners, cancels timers and springs, disconnects observers, releases pointer capture and removes its overlays. Reconnecting reinstates its behavior.

Robustness. Fluid type and gutters, container queries, logical properties, RTL preview, minimum 44px controls, native dialog with focus-trap fallback, live regions, visible focus, runtime reduced-motion changes, static first paint, generic state panels, chart zero/invalid data handling and safe textContent rendering. Chrome/Safari/Firefox fallbacks exist for View Transitions, scroll timelines, container queries, dialogs, IntersectionObserver and ResizeObserver.

Motion & performance. Transform and opacity animations only; highlights translate static gradients instead of animating paint. A shared time-correct spring solver, transform curtain chart trace, independently rolling digits, a FLIP nav panel, native scroll depth and a View Transitions theme change provide six signature moments. Geometry reads happen before batched writes. Springs settle and release their animation frame; observers gate live work; will-change is limited to active gestures.

Checks. The harness verifies 320px overflow and touch targets, source-order focus, command keyboard navigation and trap, runtime reduced motion, all ten empty states, zero and invalid chart data, RTL width, toast queue, disconnect cleanup and internal link containment. These checks do not replace assistive-technology testing or real-device browser testing.
